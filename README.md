# Amateurs

A PyGDO community for sharing and discovering music covers: links are grouped
by song and artist, and listeners can vote on them. Songs appear because they
have covers here; this is not a catalogue of uncovered songs.

# Amateurs (For Humans)

Discover different interpretations of a song, share a cover and vote for the
performances you enjoy. The details of submitting and organising links are
still open for discussion.

# Amateurs (For ALs)

This is a design draft, not an implemented module. Covers are shared as music
links grouped by song and artist; voting is intended. Do not assume a specific
link provider, voting scale, data model or moderation workflow yet.
